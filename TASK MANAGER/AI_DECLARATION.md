# Declaración de uso de Inteligencia Artificial

## 1. Herramienta utilizada

Para esta actividad utilicé ChatGPT como una herramienta de consulta y apoyo durante el desarrollo de TaskManager, principalmente para resolver dudas, revisar fragmentos de código y comprender algunos conceptos que no habíamos trabajado en las prácticas de clase.

## 2. ¿Para qué utilicé ChatGPT?

Lo utilicé para consultar dudas relacionadas con la sintaxis de JavaScript, comprobar algunos fragmentos de código y recibir sugerencias para organizar mejor las funcionalidades de la aplicación.

También me sirvió para investigar temas nuevos que solicitaba la actividad, como el uso de `localStorage`, las consultas a una API mediante `fetch()` y el funcionamiento de `CustomEvent`.

En general, procuré utilizar los conocimientos y métodos vistos en clase, consultando la herramienta cuando necesitaba aclarar algo o conocer una función nueva.

## 3. Ejemplos de consultas realizadas

Algunas de las consultas estuvieron relacionadas con:

- Cómo guardar y recuperar las tareas utilizando `localStorage`.
- Cómo obtener información de JSONPlaceholder mediante `fetch()` y manejar posibles errores de conexión.
- Cómo utilizar `CustomEvent` para actualizar las estadísticas cuando se modifica una tarea.

Estas consultas me ayudaron a comprender mejor el funcionamiento de esas herramientas y su aplicación dentro del proyecto.

## 4. Revisión y ajustes

Durante el desarrollo revisé el código y realicé pruebas en el navegador para comprobar que las funcionalidades trabajaran correctamente.

También comprobé que las tareas importadas desde la API no se duplicaran y que los cambios permanecieran guardados después de actualizar la página.

## 5. Responsabilidad del trabajo

ChatGPT fue utilizado como material de consulta y apoyo técnico. Las funcionalidades se fueron comprobando mediante pruebas en el navegador, utilizando también la consola y las herramientas de desarrollo de Chrome para verificar los resultados.
